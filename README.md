# 제타 프로필 자동감지 (모브 프로필 사진 추가)

제타 웹 채팅방에서 유저 프로필과 등장인물을 확인하고, 모브의 이름·설명·사진을 등록할 수 있는 유저스크립트입니다.

## 설치

1. 브라우저에서 Tampermonkey를 설치하고 제타 사이트에서 실행을 허용합니다.
2. [유저스크립트 1.0.3 설치](https://raw.githubusercontent.com/casualJH/zeta-profiles-mob/main/zeta-profiles-mob.user.js)를 엽니다.
3. 기존 `zeta-current-profiles`, `zeta-mob-photos` 또는 이전 통합본이 별도로 활성화되어 있다면 끄고 제타 채팅방을 새로고침합니다.

## 사용 방법

- 채팅방에서 **프로필**을 누르면 현재 유저 프로필과 등장인물 카드가 열립니다. 버튼을 끌어서 옮기면 위치를 기억합니다.
- 등장인물 아래의 **모브 추가**에서 채팅에 표시된 이름과 같은 이름을 입력하고 사진을 선택합니다. PNG, JPG, WEBP, GIF를 지원하며 사진은 최대 5MB입니다.
- 등록한 사진은 해당 채팅방에서 이름이 일치하는 발화자의 아바타에 적용됩니다. 모브 카드의 **수정**과 **삭제**로 등록 정보를 관리할 수 있습니다. 이미 등록한 이름의 설명을 바꿀 때는 사진을 다시 선택할 필요가 없습니다.
- 닫기 왼쪽의 해·달 버튼으로 테마를 바꿀 수 있습니다. 처음에는 기기 설정을 따르고 이후에는 선택을 기억합니다.

## 백업과 복원

**백업/복원**에서 모든 채팅방의 모브 이름·설명·사진을 JSON으로 내려받거나 복원할 수 있습니다. 같은 방에 같은 이름이 있으면 확인 후 백업 정보로 덮어씁니다. 백업 파일에는 등록한 사진과 설명이 포함됩니다.

모브 데이터는 제타 사이트의 브라우저 저장소에 저장됩니다. 다른 기기나 브라우저로 옮길 때는 백업 파일을 사용하세요. 프로필 감지는 제타 웹페이지가 불러온 프로필 응답을 사용합니다. 제타 웹 화면 구조가 바뀌면 감지나 아바타 교체에 영향이 있을 수 있습니다.

프로필 감지 기능은 [zeta-current-profiles](https://github.com/casualJH/zeta-current-profiles)를 바탕으로 합니다.
